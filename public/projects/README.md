# Project Image Upload Guide

You can easily update the images for any project on your website by adding your app screenshot files to the corresponding folder below.

## How to Update Images:
1. Save your app screenshot as `.png` or `.jpg`.
2. Rename it to match the exact filename listed above (e.g. `cover.png`, `screenshot1.png`, `screenshot2.png`, `screenshot3.png`).
3. Copy/paste the image file into the project's folder in `public/projects/<project-folder>/`.
4. Refresh your website — the new picture will automatically display and auto-scroll in the slideshow!
